# 🚀 Abdul Hannan's Space — Interactive 3D Portfolio

An interactive, space-themed developer portfolio built to present my skills, projects and achievements through an immersive 3D exploration experience.

🌐 **Live Website:** https://abdul-hannan-space.vercel.app/

## 🌌 Overview

Instead of a traditional portfolio website, I wanted to create an experience where visitors can explore different planetary environments using a rocket.

## ✨ Features

- 🚀 Interactive rocket navigation
- 🪐 Multiple 3D planetary environments
- 💻 Interactive project showcase
- 👨‍💻 About Me and technical skills
- 🏆 Achievement system
- ☄️ Asteroid and collision mechanics
- 📱 Desktop and mobile support

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js
- WebGL
- LocalStorage
